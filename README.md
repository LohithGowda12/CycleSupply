## 🚀 About This Project

CycleSupply was developed using a vibe coding approach with Antigravity ⚡, focusing on rapid prototyping and practical learning.

The project is a full-stack e-commerce prototype for bicycle parts 🚴‍♂️, where I explored modern web technologies 💻, component-based UI design 🎨, and cloud deployment ☁️ on Google Cloud.

🔗 **Live Project:** https://cycle-supply-193664692195.us-central1.run.app

This experience helped me understand real-world development workflows 🔄, debugging 🛠️, and system design 🧠 at a foundational level.
